# AuraX Finder Preview

Open `index.html` in a desktop browser and use responsive/mobile preview around
390 px width. This is a static visual mock for fast layout iteration; real
network discovery still runs in the native Android app.

Suggested workflow:

1. Tune spacing, text, cards, and colors here.
2. Mirror the final visual choices in `app/src/main/java/com/aurax/finder/MainActivity.java`.
3. Build a new APK only after the layout is approved.
