Privacy Policy

AuraX Finder

Effective Date

June 30, 2026

Overview

AuraX Finder is a companion application for AuraX devices. The app is used to find AuraX devices on the local Wi-Fi network and to open their local web control interface.

Information Processed by the App

AuraX Finder may display technical information provided by nearby AuraX devices on the local network, such as:

  • device name;
  • local IP address;
  • battery status, if provided by the device;
  • Wi-Fi signal strength;
  • synchronization channel status.

This information is used only to show available AuraX devices in the app and to connect to their local control interface.

Personal Data Collection

AuraX Finder does not collect personal data from users. The app does not require registration, login, or user accounts. The app does not send personal data to our servers.

Data Sharing

AuraX Finder does not share user data with third parties. The app does not use advertising networks, analytics tools, or tracking technologies.

Network Communication

AuraX Finder communicates with AuraX devices on the user's local Wi-Fi network. Communication takes place between the mobile device and the AuraX device, for example through the device's local IP address.

Files and Web Interface

AuraX Finder can open the local web interface of an AuraX device inside the app. If the user manually selects a file or starts a download in that web interface, the action is performed only based on the user's request.

Children

AuraX Finder is not intended for children. The app is intended for users of AuraX hardware and for technical setup and control of AuraX devices.

Changes to This Privacy Policy

We may update this Privacy Policy from time to time. The current version will always be available on this page.
