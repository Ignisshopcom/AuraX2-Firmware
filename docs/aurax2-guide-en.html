Set up AuraX2 without guesswork

This guide explains how to find AuraX2, connect it to Wi-Fi, and control it from a phone, a computer, or a laptop running Ignis Studio. The important rule is simple: AuraX devices, your phone, and your computer must be on the same network. That network can be created by a router, a phone hotspot, or a laptop hotspot.

Quick Start

Best option

Connect AuraX2, your phone, and the computer running Ignis Studio to the same Wi-Fi router. A router is the most stable solution when using multiple devices. You can then control AuraX2 from a phone or PC through http://aurax.local, through its IP address, or through Ignis.APP.

Rescue network AuraX-XXXX

If AuraX2 cannot connect to the saved Wi-Fi network, it automatically creates its own AuraX-XXXX Wi-Fi. This makes it possible to always connect to the device, change Wi-Fi settings, or control it directly for temporary use.

Network without a router

A shared network can also be created by a phone hotspot or a laptop hotspot. Connect AuraX2 and the device you want to control it from to that same network.

Firmware update notice

When AuraX2 has internet access, it can quietly check whether a newer firmware version is available. If an update exists, the notification appears in Settings. The update will not start by itself without user confirmation.

Shared Wi-Fi network: router or hotspot

1

Choose the Wi-Fi source

A regular Wi-Fi router is the best option. If a router is not available, the network can be created by a phone hotspot or a laptop hotspot.

2

Connect everything to the same network

Connect AuraX2 devices, your phone, and the computer running Ignis Studio to the same Wi-Fi network. Once they are on the same network, they can communicate.

3

Control from phone or computer

Open a browser on your phone or PC and enter http://aurax.local. This opens the AuraX2 web control page without installing an app.

4

Ignis Studio shows IP addresses

Use Scan in Ignis Studio. It will search for AuraX2 devices on the same network and show the IP address of each device.

5

The app is optional

Once you know aurax.local or the IP address, open it in a browser on your phone or PC. Control runs directly from the device web page.

6

If aurax.local does not open

Open the device IP address directly, for example http://10.91.105.247. You can find the IP address in Ignis Studio after pressing Scan.

Recommendation

Use a router when you want to control several props or devices at the same time. A phone or laptop hotspot can work, but a router is more stable. You can control devices without the app: scan in Ignis Studio, copy the IP address, and open it in a browser.

When AuraX2 broadcasts its own AuraX-XXXX Wi-Fi

This is the rescue mode

If AuraX2 cannot connect to the configured Wi-Fi network, it automatically starts its own AuraX-XXXX Wi-Fi. This is intentional: it lets you reach the device even if the router password changed, the hotspot was turned off, or the device is being used in a new location.

1

Find the AuraX-XXXX network

In your Wi-Fi list, choose a network such as AuraX-7772. The number is different for each device so multiple units do not look identical.

2

Stay connected even without internet

Your phone may say that the network has no internet. This is normal. Choose Stay connected or Yes.

3

Open the settings page

If the page does not open automatically, enter http://aurax.local. If that does not work, enter http://192.168.4.1.

4

Set Wi-Fi

In Settings, enter the Wi-Fi name and password. After saving, AuraX2 connects to that network and turns off its own setup Wi-Fi.

Important for Android

If the phone keeps disconnecting from AuraX-XXXX, temporarily turn off mobile data or confirm in the phone notification that you want to stay connected even without internet.

Ignis.APP

Ignis.APP is mainly a convenient way to avoid typing IP addresses. It searches for AuraX2 devices on the local network and opens their web control page when you tap a device.

1

Put the phone on the same Wi-Fi

Your phone and AuraX2 must be on the same local network. A home or venue router is the most reliable setup.

2

Press Scan

The app shows found devices with their name, IP address, battery state, Wi-Fi signal, and sync channels.

3

Tap a device

The control page for that AuraX2 device opens.

AuraX2 web control

Programs

Upload, delete, and start programs exported from Ignis Studio. AuraX2 checks free space and upload integrity.

Colors

Select colors, brightness, and prepared color palettes for effects that use color settings.

Effects

Run instant effects without uploading a program. Each effect shows only the controls that make sense for that effect.

Settings

Device name, Wi-Fi, firmware status, update notifications, firmware update, and reboot. Do not change Advanced settings without consultation or exact knowledge of the device.

ON / OFF

OFF turns LEDs off. ON resumes the last running program or effect.

Device status

The interface shows the IP address, Wi-Fi signal, battery state, and other useful status information.

Uploading programs from Ignis Studio

1

Create the program in Ignis Studio

Prepare the program in Ignis Studio and export it for AuraX2. If you are not sure about the project settings, verify them before uploading.

2

Upload directly to the device

Open Programs in AuraX2, choose the file, and upload it. Upload progress is shown on screen.

3

Start the program

Select the slot or program and press START. STOP stops the program.

What AuraX2 checks

  • Whether there is enough free space on the device.
  • Whether the file was uploaded correctly.
  • Whether a program, effect, or blackout state is active.

Synchronizing multiple devices

When to use Sync

Turn Sync on when you want one control action to change programs, colors, effects, or brightness on multiple devices at once. Devices must be on the same network and in the same sync channel.

channels 1-10 multiple devices shared START

When to turn Sync off

If you want to control only one specific prop or device, turn Sync off. Commands are then sent only to the device currently open in the browser.

single device local control

Common settings

Setting Purpose Recommendation
Device name Name shown in the app, device list, and network. Use a practical name such as stage-left or staff-01.
Wi-Fi SSID / Password The network AuraX2 should connect to. Use one stable Wi-Fi network when controlling multiple devices.
Advanced settings Service area for hardware-specific configuration. Do not change without consultation or exact knowledge of the device.
Firmware update Current firmware version, check for newer firmware, and manual firmware update. AuraX2 can notify you when a newer version is available. Update only with stable power and do not interrupt the upload.

Troubleshooting

Problem What to try
aurax.local does not open Check that you are on the same Wi-Fi network. Press Scan in Ignis Studio and open the device IP address. On AuraX setup Wi-Fi, try 192.168.4.1.
The phone disconnects from AuraX-XXXX Confirm that you want to stay connected to a network without internet. If needed, temporarily disable mobile data or automatic Wi-Fi switching.
Ignis.APP finds no devices Put your phone, computer, and AuraX2 on the same Wi-Fi. Try Scan again in Ignis Studio. If the phone is used as a hotspot, some phones limit client discovery; use the IP address or a router instead.
AuraX-XXXX disappeared after setting Wi-Fi This is correct. The device connected to the selected network and turned off its own setup Wi-Fi.
Program upload fails Check free space and the file exported from Ignis Studio. If upload through the app is blocked by the phone, try a regular browser.
The device does not respond Disconnect and reconnect power. Wait up to 60 seconds. If it cannot connect to the saved Wi-Fi, it should start broadcasting AuraX-XXXX.

The simple rule

Router is best, hotspot is backup

Whenever possible, connect all AuraX2 devices, your phone, and your computer to one Wi-Fi router. If no router is available, a phone or laptop can create a hotspot. Then use aurax.local, the IP address from Ignis Studio, or Ignis.APP to open the device.
